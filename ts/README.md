# ts/

Paquete TypeScript para el panel de coordinadores y el publicador de `backend-supabase` (lib-mapa#4). Se usa como dependencia npm desde GitHub con el tag de la release (`github:Colportores/lib-mapa#vX.Y.Z`); nada se publica en npm.

Trae los tokens generados (`src/tokens.g.ts`) y los fragmentos de capa. Los componentes de pantalla se quedan en cada front.
